# QPD – Quantum Production Dashboard

## My Humble Beginning (2022)

**QPD – Quantum Production Dashboard** was one of my earliest software projects, developed in **2022 during my Petroleum Engineering studies**. While the name may sound ambitious today, the project represented my first serious attempt to combine engineering thinking, data analysis, and software development into a practical dashboard application.

Looking back, QPD reflects the curiosity and enthusiasm of a student exploring how operational and production data could be transformed into actionable insights through visualization and analytics. Although simple compared to my current engineering and AI projects, it laid the foundation for my later work in data engineering, machine learning, petroleum analytics, and scientific software development.

# Project Overview

QPD (Quantum Production Dashboard) is a lightweight analytics platform designed to monitor, analyze, and visualize production-related metrics through an interactive dashboard interface.

The project was created as an educational exercise to explore:

* Real-time data visualization
* Engineering data analysis
* Dashboard design principles
* Python-based analytics workflows
* User-focused reporting systems

The application provides an intuitive environment for viewing operational data, generating insights, and supporting data-driven decision making.

---

# Key Features

### Live Data Visualization

Monitor incoming production metrics through dynamic charts and graphical displays.

### Interactive Dashboard

Customizable widgets and layouts allowing users to focus on the information most relevant to their workflow.

### Performance Analytics

Analyze production trends and operational indicators using statistical summaries and visual analytics.

### Secure User Access

Basic authentication mechanisms for managing dashboard access and protecting data visibility.

### Reporting & Export

Generate exportable reports and data summaries for presentations, documentation, and operational reviews.

### Data Integration

Support for connecting to external data sources through APIs and streaming technologies.

# Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/qpd-quantum-production-dashboard.git
```

Navigate to the project directory:

```bash
cd qpd-quantum-production-dashboard
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the environment:

Linux / macOS

```bash
source venv/bin/activate
```

Windows

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# Running the Application

Start the dashboard:

```bash
streamlit run app.py
```

Open:

```text
http://localhost:8501
```

in your browser.
